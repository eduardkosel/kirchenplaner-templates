# Vorschaubilder

Echte Browseraufnahmen der Templates mit lokalen Testterminen. Desktop: Browserbreite 1280 Pixel; Smartphone: 390 Pixel. Die Bilder zeigen die mitgelieferte Gestaltung ohne Bootstrap.

## Gottesdienste

Die zusätzliche Variante **Gottesdienste** wurde mit den unveränderten TYPO3-Controllern gerendert. Die Beispieltermine sind Testdaten, keine aktuellen Gottesdienstzeiten.
